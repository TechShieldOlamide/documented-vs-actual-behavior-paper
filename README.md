# When the Paper Trail Lies

A working paper arguing that the gap between an AI system's documented configuration and its actual behavior should be treated as its own category of governance risk, not an afterthought of conventional compliance review.

**Full paper:** [Working_Paper.pdf](./Working_Paper.pdf)

## Summary

Governance, risk, and compliance (GRC) practice generally treats documentation as a reliable proxy for system behavior. This paper argues, from direct practitioner experience, that this assumption is increasingly unsafe for AI-driven systems specifically. Drawing on two original projects, a structured adversarial security test of an AI system ([ai-prompt-injection-testing-sandbox](https://github.com/TechShieldOlamide/ai-prompt-injection-testing-sandbox)) and a multi-framework compliance gap assessment of a fintech architecture ([secure-architecture-fintech-lending](https://github.com/TechShieldOlamide/secure-architecture-fintech-lending)), it presents concrete evidence of that gap in practice and argues for a shift in how GRC methodology accounts for it.
